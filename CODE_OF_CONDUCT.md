# Code of Conduct

This project follows a simple maintainer-enforced conduct rule: be respectful, stay on topic, and
do not harass contributors, users, upstream authors, or optional compatibility mod authors.

Unacceptable behavior includes personal attacks, hate speech, repeated off-topic demands, posting
private information, or pressuring upstream projects to support issues caused by this unofficial
port. Maintainers may hide, lock or delete disruptive content and block repeat offenders.
